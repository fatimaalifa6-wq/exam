# Smart Exam Grader

تطبيق Flask عربي لإنشاء الاختبارات وتصحيح أوراق الإجابة تلقائيًا بتقنية
OMR (قراءة الدوائر المظللة).

## ما الذي يفعله التطبيق؟

- إنشاء اختبار من 4 إلى 40 سؤالًا، بشرط أن يكون العدد من مضاعفات 4.
- حفظ بيانات الاختبار والإجابات الصحيحة داخل `data/exams`.
- توليد ورقة إجابة PDF قابلة للطباعة.
- رفع صورة ورقة الطالب بصيغة JPG أو PNG أو WEBP.
- اكتشاف ورقة الإجابة وتصحيح الدوائر باستخدام OpenCV.
- عرض النتيجة التفصيلية لكل سؤال وحفظها داخل `data/results`.

## التشغيل على Replit

1. افتحي المشروع واضغطي **Run**.
2. افتحي تبويب **Preview**.
3. اختاري **إنشاء اختبار** وأدخلي بيانات الأسئلة والإجابات الصحيحة.
4. نزّلي ملف PDF واطبعيه.
5. بعد الحل، صوّري الورقة كاملة مع ظهور العلامات السوداء الأربع في الزوايا.
6. اختاري **تصحيح ورقة**، ثم حددي الاختبار وارفعِي الصورة.

## التشغيل من الطرفية

```bash
pip install -r requirements.txt
python main.py
```

يعمل التطبيق على المنفذ `5000`.

## ملاحظات التصوير

- استخدمي ورقة A4 غير مطوية.
- صوّري الصفحة كاملة من أعلى وبإضاءة متوازنة.
- تأكدي من ظهور العلامات الأربع الموجودة في زوايا الورقة.
- يجب تظليل دائرة واحدة فقط لكل سؤال بقلم داكن.
